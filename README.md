# Transactions Dispute Portal

Customers view their bank transactions, dispute them and see a history of their disputes. Back-office agents work the dispute queue.

## Stack

- Java 25 + Spring Boot 4.1
- Vue 3 + Quasar 2 (TypeScript)
- PostgreSQL 18
- Docker

## Repository layout

```
backend/    Spring Boot API
frontend/   Quasar single-page app
docs/       API contract and design documentation
```

Build, run and test instructions are added with the first runnable version.
